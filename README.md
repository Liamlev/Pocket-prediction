# Pocket Prediction – test build

Static site, no server code. Host the files in this folder on any HTTPS host (GitHub Pages works).
On its own site the live camera works, which enables the sweep scan and face-down mode.

Everything runs on the phone. Internet is only needed to load the page the first time.
